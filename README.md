# Replayable RGB-D Perception and Semantic Mapping System

A modular RGB-D perception and semantic mapping system built using public timestamped sensor sequences.

## Planned Features

- RGB-D dataset adapters
- Multi-frame 3D mapping
- Semantic voxel mapping
- ROS2 sensor replay
- C++ mapping core
- Robustness and performance evaluation
